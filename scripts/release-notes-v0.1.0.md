# TKClassic v0.1.0

`TKClassic-v0.1.0.zip` contains the generated DAT files for the classic graphics replacements. It includes body, weapon, monster, riding, and tile changes.

Back up the corresponding files in your NexusTK `Data` folder, then extract the ZIP and copy the files from its `Release` folder into `Data`.

To revert, download `TKClassic-v0.1.0-original-nexus.zip` and copy the DAT files from its `nexus/Data` folder into your NexusTK `Data` folder, replacing the matching files. This restores the original Nexus versions of every file in the replacement ZIP.

Each ZIP has its own `.sha256` file. Verify a download with `sha256sum -c <zip-name>.sha256`.
